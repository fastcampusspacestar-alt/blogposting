## 십신이란

십신(十神)이란 일간(日干)을 기준으로 다른 오행 및 음양이 맺는 관계를 열 가지로 분류한 것이다.

- **비겁(比劫)**: 비견(比肩) + 겁재(劫財) — 일간과 같은 오행
- **식상(食傷)**: 식신(食神) + 상관(傷官) — 일간이 생하는 오행
- **재성(財星)**: 편재(偏財) + 정재(正財) — 일간이 극하는 오행
- **관성(官星)**: 편관(偏官) + 정관(正官) — 일간을 극하는 오행
- **인성(印星)**: 편인(偏印) + 정인(正印) — 일간을 생하는 오행

## 음양에 따른 구분

같은 오행 관계라도 음양이 같으면 '편(偏)', 다르면 '정(正)'이 붙는다.

예컨대 甲木 일간이 戊土를 만나면 **편재**, 己土를 만나면 **정재**가 된다.

## 십신이 나타내는 의미

| 십신 | 대표 의미 |
|------|-----------|
| 비견 | 형제, 동료, 경쟁자, 자존심 |
| 겁재 | 강한 경쟁, 빼앗김, 추진력 |
| 식신 | 재능, 표현, 먹을복, 여유 |
| 상관 | 총명함, 반항기, 예술성 |
| 편재 | 편벌이, 투기, 아버지(남명) |
| 정재 | 정직한 재물, 배우자(남명) |
| 편관 | 칠살, 직업권위, 도전과 극복 |
| 정관 | 명예, 직위, 규범과 책임 |
| 편인 | 편학, 특이한 재능, 고독 |
| 정인 | 학문, 배움, 어머니의 사랑 |

> **주의**: 십신의 '길흉'은 단독으로 판단할 수 없다. 왕쇠강약(旺衰强弱)과 전체 구조를 보아야 한다. 정관(正官)이 많아도 흉이 될 수 있고, 상관(傷官)이 있어도 기묘한 쓰임이 있다.

## 십신을 보는 순서

1. 일간(日干)의 강약을 먼저 살핀다
2. 월지(月支)의 십신을 확인한다 — 이것이 핵심
3. 용신(用神)을 정하고, 그에 맞는 십신의 도움을 찾는다

이 세 단계만으로도 명식의 큰 그림이 보이기 시작한다.
